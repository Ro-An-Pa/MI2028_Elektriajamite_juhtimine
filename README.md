# MI2028_Elektriajamite_juhtimine
Coursework completed in 2026 as part of the course MI2028_Elektriajamite_juhtimine at the Estonian University of Life Sciences.

Corse goal:
To develop basic understanding of programming, terminology and methodology. Create knowledge in programming to support other related courses in the curriculum.

After successful studies the student:
* knows basic electric drive control principles, feedback, and utilizes them in order to create electric drive control systems;
* is able to evaluate different types of drives and control methods, choose suitable based on the application;
* knows numeric control, filters, models, algorithms principles and software, is able to implement them;
* is aware of main properties of microprocessors and is able to choose a suitable one for drive control;
* knows and implements generic programmable controllers and drive controllers.


Generalized structure of an electric drive. Continuous and discrete signals in electric drive. Signal processors and their applications. Analog-digital converters and digital-analog converters. Pulsewidth control and converters. Numeric control, filters, models and algorithms. Software based numeric control, filters, models and applications. Stability and control quality of numeric control drives. Controlling electric drive with generic programmable controllers and special drive controllers. Generic functions of different Drives and designated controllers. Synthesis of speed, torque and position control systems of an electric drive.

 
This includes only finalized version of the the base code developed throughout the course. The development history, including previous versions and subsequent modifications, can be viewed in the user's Vllem GitHub repository, MI2028_Elektriajamite_juhtimine.
